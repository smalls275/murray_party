# Murray Holiday Party Invite

This project is a playful digital invite for the Murray holiday party on October 12, 2026, at 5:30 PM in Fredericksburg, Virginia.

## Included

- A festive landing page with party details
- Directions link to the house
- Add-to-calendar button
- RSVP tracking with a guest list and status totals
- Kid-friendly but grown-up holiday party tone

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static server:

```bash
python -m http.server 8000
```

Then browse to http://localhost:8000.

## RSVP tracker

Guest responses are saved in the browser using `localStorage`, so the tracker works without a backend.
